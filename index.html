01 / 06 YAHCW (Hot Corners)
C# · .NET · WinForms · Win32 API · DWM

YAHCW (Yet Another Hot Corners for Windows)

Utilitário de produtividade nativo para Windows que integra ativação ágil por cantos de tela (hot corners), visualização de miniaturas em tempo real via Desktop Window Manager (DWM), ajuste de luminosidade via DDC/CI e chaveamento de áudio COM.

Decisões Arquiteturais & Integração Win32

  • Comunicação Interprocessos por Named Pipe: O executável principal desacopla o controle para o processo auxiliar BrightTray através de uma Named Pipe local, garantindo isolamento de privilégios.
  • Controle de Brilho Físico (DDC/CI & WMI): Emite opcodes VCP padrão (0x10 para luminância) diretamente ao barramento I2C/DDC dos monitores externos via dxva2.dll, com fallback dinâmico para WMI em notebooks.
  • Chaveamento de Áudio COM: Interage com a interface nativa IPolicyConfig via invocação COM pontual, permitindo alternar dispositivos sem reiniciar fluxos ativos.
  • Miniaturas Vivas DWM: Utiliza DwmRegisterThumbnail e DwmUpdateThumbnailProperties para compor miniaturas renderizadas pela GPU sem sobrecarregar a CPU.

Ressalvas Técnicas & Demonstração Ilustrativa

A demonstração abaixo é ilustrativa e roda no navegador: o ajuste de brilho aplica um filtro visual simulado (CSS brightness), demonstrando o fluxo operacional que o executável C# realiza no hardware via VCP 0x10.

02 / 06 tuya-smart-lamps
Python 3 · Sockets TCP · OpenAPI · SSE na UI

tuya-smart-lamps

Sistema de automação para lâmpadas inteligentes priorizando sockets TCP diretos na rede local Wi-Fi na porta 6668, com algoritmo de contingência que comuta para a OpenAPI da Tuya em nuvem em caso de queda do enlace direto.

Topologia de Rede & Arquitetura Híbrida

  • Sessão TCP Persistente Local: Conexão de socket criptografado com a porta 6668 do dispositivo na LAN, mantendo independência da internet pública.
  • Fallback OpenAPI em Nuvem: Se o watchdog local detectar timeouts consecutivos, as requisições são roteadas para a OpenAPI da Tuya na nuvem, com telemetria via Server-Sent Events (SSE) na UI.
  • Latências Simuladas para Demonstração: Os valores de latência exibidos no teste (4ms local vs 148ms nuvem) são valores simulados para ilustrar o contraste entre rota LAN direta e trânsito externo de nuvem.

03 / 06 gaming-fps-hud
C++17 · Vulkan API · vkQueuePresentKHR · Qt 6 Quick · KDE Wayland

gaming-fps-hud

Camada de telemetria em C++17 para Linux/Wayland que observa chamadas vkQueuePresentKHR na fila gráfica da GPU, gerando métricas de frame-time e 1% low serializadas como snapshots JSON atômicos para um HUD em Qt 6 Quick.

Observação Vulkan & Snapshots Atômicos

  • Observação Vulkan Sem Bloqueio: Mede deltas temporais entre apresentações gráficas com relógio monotônico de alta precisão (std::chrono::steady_clock).
  • Snapshots JSON Atômicos: A amostragem de telemetria é formatada em estruturas JSON atômicas consumidas pela interface gráfica.
  • Cenários Sintéticos Demonstrativos: As métricas exibidas nos seletores (144 FPS estável, stutter, 60 FPS) são dados sintetizados para demonstração didática da interface.

def extrair_elementos_unicos(colecao_primaria, colecao_secundaria):
    """
    Retorna elementos exclusivos da primeira colecao
    utilizando a operacao set.difference().
    """
    conjunto_a = set(colecao_primaria)
    conjunto_b = set(colecao_secundaria)
    return sorted(list(conjunto_a.difference(conjunto_b)))
def converter_taxa_anual_mensal(taxa_anual_percentual):
    """
    Converte taxa anual efetiva em taxa mensal equivalente.
    """
    fator_anual = 1.0 + (taxa_anual_percentual / 100.0)
    taxa_mensal = (fator_anual ** (1.0 / 12.0)) - 1.0
    return taxa_mensal
def ler_linhas_validas(caminho_arquivo):
    """
    Abre arquivo com context manager e descarta linhas vazias.
    """
    linhas_limpas = []
    with open(caminho_arquivo, mode='r', encoding='utf-8') as arquivo:
        for linha in arquivo:
            texto = linha.strip()
            if texto:
                linhas_limpas.append(texto)
    return linhas_limpas

06 / 06 Laboratório Financeiro
Modelagem Quantitativa · Taxa Efetiva · Gráfico Reativo SVG

Simulador Quantitativo de Juros Compostos

Motor matemático determinístico preservado em finance-lab.js que calcula a evolução temporal de patrimônio a partir da taxa anual efetiva convertida em taxa mensal equivalente, com aportes regulares no final de cada período.

Fundamentos Matemáticos & Validação

  • Conversão de Taxa Efetiva: Aplica a relação estrita taxaMensal = (1 + taxaAnual / 100) ** (1 / 12) - 1, calculada com precisão via Math.expm1(Math.log1p(annualRatePercent / 100) / 12).
  • Validação Estrita & Preservação de Estado: Entradas inválidas, nulas ou prazos fracionários (ex: 12.5 meses) são rejeitados pelo validador, preservando intacto o gráfico da simulação anterior e exibindo mensagem diagnóstica.
  • Propósito Acadêmico: Instrumento desenvolvido para estudos quantitativos de trajetórias de capitalização, sem constituir recomendação financeira.
