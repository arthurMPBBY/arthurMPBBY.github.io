[01] Telemetria & Sistemas

gaming-fps-hud

HUD em C++ para Linux que mede a cadência e intervalos de entrega de quadros em tempo real via Vulkan (vkQueuePresentKHR), com exibição desacoplada em Wayland LayerShell via Qt 6 Quick.

C++17 Vulkan API Qt 6 Quick Wayland
Como funciona

O aplicativo intercepta as chamadas de renderização via Vulkan no Linux, calcula métricas de latência e cadência de quadros em C++, e transmite as estatísticas para um overlay desacoplado renderizado em Wayland LayerShell com Qt 6 Quick.

Apresentação Vulkan vkQueuePresentKHR
Coleta C++ Frame Time & Latência
Overlay Wayland Qt 6 Quick / LayerShell
  1. Apresentação Vulkan: Intercepta a fila de apresentação gráfica via vkQueuePresentKHR.
  2. Coleta em C++: Mede os intervalos entre quadros sem interferir na execução do jogo.
  3. Exibição Wayland: Transmite dados a um processo isolado em Qt 6 Quick sobre LayerShell.

[02] IoT & Redes

tuya-smart-lamps

Controle de dispositivos residenciais em Python via rede local direta por sockets TCP (<10ms de latência), eventos em tempo real com SSE, aplicativo de bandeja em PyQt6 e contingência automática via Tuya Cloud API.

Python 3.10+ TCP Sockets & Heartbeat PyQt6 Server-Sent Events
Como funciona

A interface gráfica em PyQt6 envia comandos a um serviço local em Python, que estabelece conexões diretas por sockets TCP com as lâmpadas (<10ms) mantendo heartbeat contínuo. Caso a rede local falhe, a API Tuya Cloud é acionada como contingência automática.

Interface PyQt6 Bandeja do Sistema
Serviço Python Local Eventos SSE & Router
Lâmpada Local (TCP) <10ms / Cloud Fallback
  1. Controle na Bandeja: Interface nativa PyQt6 dispara ações instantâneas do usuário.
  2. Serviço Local em Python: Mantém sessões TCP ativas com pacote de heartbeat periódico.
  3. Execução na Rede Local: Entrega comandos em menos de 10ms com fallback para a nuvem Tuya.
